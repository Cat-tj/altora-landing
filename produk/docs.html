Pertanyaan umum

Apa bedanya dengan menyimpan di cloud publik?

Dokumen tersimpan di server atau cloud milik organisasi Anda, dan aksesnya diatur oleh admin Anda sendiri.

Apakah dokumen lama bisa dipindahkan?

Bisa. Kami bantu memindahkan dokumen dan menyusun ulang strukturnya.

Bisakah dipakai bersama Altora Private AI?

Bisa. Dokumen internal dapat menjadi sumber jawaban asisten AI yang juga berjalan di server Anda.
